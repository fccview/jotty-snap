# OH SNAP!

Snap any web page into a [Jotty](https://jotty.page) note.

## What it does

- Three modes: **Article** (Mozilla Readability), **Full page**, and **Selection**, you can also right-click a page or a selection.
- Pick any existing category, or type a new path0 like `Reading/Articles` and Jotty creates it.
- Tags are added as `#hashtags`, your existing tags will autocomplete.
- Optional AI tagging that prefers the tags and categories you already use. It supports OpenAI, OpenRouter, Ollama, llama.cpp, vLLM, LM Studio, Gemini, Anthropic, Perplexity and any OpenAI-compatible server.
- The popup uses your Jotty theme, including custom themes and custom CSS.
- Optionally stores the source URL, site, author and dates in the note frontmatter, and adds a source link at the bottom.

## Requirements

[Jotty](https://jotty.page) >= 1.29.2
